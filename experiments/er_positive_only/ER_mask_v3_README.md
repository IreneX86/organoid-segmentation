# ER mask v3（由 ER.tif 生成），5 张示例（2026-11-02）

v3 在 v2 的基础上加了两条规则，规则固定，不针对单张图调参：
1. **去除亮颗粒**：只删除同时满足两个条件的点——外形是圆的（两个方向的 Hessian 特征值都为负，较小值至少是较大值的 0.6 倍），而且亮度达到附近 30 px 内细管第 90 百分位数亮度的 2 倍以上。删除时整个颗粒一起去掉。网络的分叉点和附近细管差不多亮，所以会保留。
   - 初版曾用中位数作参照，结果每张图误删 250–450 个分叉点，已经放弃。
2. **限制宽度**：离 mask 中心线超过 2.5 px 的像素被去掉，所以任何结构都不超过约 5 px 宽。原本就细的细管不受影响。

文件：每张切片有 `*_ER_mask_v3.tif` 和 `*_ER_positive_region.tif` 两个文件，均为 uint8，取值 0 或 255，与原图同为 1200×1200。阳性区外的 ER 状态未知，训练时应忽略。

这些是算法生成的伪标签，不是人工真值。下表的“ER 脊线”是从 ER.tif 直接算出的另一个算法参照，也不是真值。
