# ER mask v3（由 ER.tif 生成），5 张示例（2026-11-02，加入了“去小亮点”）

v3 在 v2 的基础上加了 3 条规则，规则固定，不针对单张图调参：
1. **去除亮颗粒**：外形是圆的，而且亮度达到附近 30 px 内细管第 90 百分位数亮度的 2 倍以上，就整个删掉。网络的分叉点和附近细管差不多亮，所以会保留。
2. **限制宽度**：离 mask 中心线超过 2.5 px 的像素被去掉，所以任何结构都不超过约 5 px 宽。
3. **去除小亮点**（应要求新增）：mask 中独立的一块，满足以下任一条件就删除：
   - 尺寸小于 25 px，平均亮度 ≥ 全图 mask 中位数的 1.5 倍；
   - 尺寸小于 80 px，平均亮度 ≥ 3 倍（紧凑亮团）。
   大片的网络不受影响。

**已知代价**：
- 在很亮、很致密的核周区域，少数不连续的短网络碎片会被当成小亮点删掉，例如 23300 z50 放大 B 中的几块。
- 由于另外两条规则，脊线覆盖率比 v2 低 3–16 个百分点；其中一部分原因是参照用的脊线本身也会标到亮点。

这些是算法生成的伪标签，不是人工真值。对比图中品红为保留的部分，橙色为 v3 删掉的部分。
