# Mito 标注语义盲法复核方案（仅设计，尚未执行）

**目的。** 判断冻结五折 baseline 的亮背景误报是否主要反映模型误判、人工 mask 对弱信号的标注边界，或单通道图像无法判定的区域。此复核不训练模型、不修改原始 TIFF 或 mask，也不重新选择已完成实验的模型。36 张图均属于已标注开发数据；本方案由其已查看过的 OOF 误差启发，因此结果仅用于解释与形成下一轮假设，不能充当独立的泛化检验。

## 已有证据和待检验的问题

冻结 baseline 的 36 张逐图 OOF Dice 为 0.854309 ± 0.062776。前景 ≤5% 的 7 张图平均 Dice/precision 为 0.791388/0.727167，其余 29 张约为 0.869497/0.866063，两组 recall 均约 0.877。两组每图 FP 均约 1.5 万像素；低前景图中距离人工 GT >10 原像素的 FP 比例为 27.3%，其余图为 16.0%。多数低前景 FP 局部较亮，但现有图像证据不能证明它们是非线粒体、伪影或漏标。此前亮背景 hard-negative 五折实验的 validation-only gate 选择了 0/5 折，故本复核也不以该实验的候选外层测试分数为依据。原始统计和可视化见 `reports/mito_error_analysis_20261002.md`、`reports/mito_hard_negative_5fold_20261002.md`。

## 在查看复核判断前固定的抽样

1. 以 `baseline/mito_five_fold_20261001/oof_per_image.csv` 为唯一图像级抽样表。先按人工 mask 的前景比例分为 ≤5% 与 >5%；**在各自组内**按冻结 OOF Dice 的中位数分为低/高 Dice，等于中位数的图归入高组，得到四格。各格按 SHA256(`20261008|原文件名`) 的十六进制值升序选最多 2 张；如某格不足 2 张，记录实际数量，绝不从另一格补取。这样最多复核 8 张图，既包含稀疏/密集前景，也包含各自的较好/较差预测，而不专挑单张最差图。原文件名只用于本地抽样映射，不交给复核者。
2. 每张入选图固定抽取最多 8 个相距至少 64 原像素的目标点，使用冻结 baseline 二值 OOF 预测与原 mask **仅为抽样**定义四类，每类最多 2 点：距离 GT >10 px 的 FP（其中 1 点从归一化强度和局部对比度均达到该图 GT-background p90 的候选中取，1 点从其余候选中取）；距 GT >10 px、归一化强度距前述亮 FP ≤0.05 且局部对比度达到 GT-background p90 的亮真阴性；距 GT ≤2 px 的 FP；以及已标注且预测为阳性的点。各候选类先按 SHA256(`20261008|原文件名|类别|y|x`) 升序排列，再依次取满足相互间距 ≥64 px 的点；同一位置不可重复。某类不足额则保留空缺并报告，不替换其他类别或挑选视觉上“有代表性”的点。局部对比度沿用现有误差审计的逐图 1–99.8 百分位归一化及 Gaussian σ=12 px 残差定义。抽样在打开复核图之前完成；候选数量和最终坐标保存在 **Git 忽略** 的本地审计目录。
3. 每点制作以该点为中心的 320×320 原像素输入裁剪，保持同一图像的显示映射，不单独对 crop 拉伸对比度；原图边缘不足处以中性空白填充而不平移中心。另提供同图的无标记全图供上下文判断。仅用中性十字标出待判位置。裁剪按 SHA256(`20261008|原文件名|y|x`) 重新排序并赋匿名编号；材料中不出现文件名、fold、前景比例、Dice、GT、模型预测/概率、FP/TN/TP 类别或 hard-negative 实验结果。含生物图像的复核包、坐标映射和个人判断表均留在 Git 忽略目录，不推送仓库。

## 独立专家复核

复核前由项目负责人写下当前人工标注 SOP 对“应标为 Mito”的定义和已知成像局限，冻结后交给至少 **两位熟悉该染色/成像流程的复核者**。两人先独立看输入裁剪及全图，不交流，也不查看 GT/预测。逐点记录：

- 标记位置是否有应标注的 Mito：**是 / 否 / 无法判定**；判断信心 **高 / 中 / 低**。
- 如为“否”，更接近 **其他可辨结构 / 成像伪影或噪声 / 普通亮背景 / 无法具体区分**；仅在单通道图像支持时选择具体类别。
- 若为“是”，可见结构的范围是否可清晰界定，还是存在合理边界歧义；简短记录依据（形态、连续性、局部信噪比等），不得仅凭亮度推断生物身份。

锁定第一轮判断后，第二轮才向复核者显示 **原人工 mask 轮廓，但仍不显示模型预测、概率、Dice 或 FP 类型**。逐点记录“原 mask 与上述独立判断一致 / 不一致 / 无法判定”，若不一致，区分疑似遗漏、过标、边界定义差异。第二轮不允许追改第一轮答案。由第三位熟悉 SOP 的专家对分歧进行盲法裁决；原始两人意见与分歧均保留，裁决不能抹掉它们。若无第三位专家，直接报告未裁决分歧。

## 汇总、解释与后续边界

先按**图像**、再按四个抽样格及匿名目标类型汇总，报告实际抽取数、两位复核者的原始一致率、无法判定比例，以及适用时的 Cohen κ；小格仅给计数，不把同图多个点当成独立生物样本做显著性检验。由保管匿名映射且不参与第一轮判断的人在答案锁定后解盲，分别描述远距 FP、近边界 FP、亮真阴性与阳性对照中“应标 Mito / 非 Mito / 无法判定”的分布和意见分歧。保留匿名逐点判断供复核，但 Git 只存不含原图和坐标的汇总。

- 若远距 FP 多数被一致判为**非 Mito**，说明远距亮误报是合理的模型错误假设；下一实验可预先定义单一、温和的训练折内对比度/背景增强，并仅在相应 fold 的 training 数据拟合或应用，使用 validation-only 选择。该判断本身不是 Dice 提升证据。
- 若远距 FP 常被一致判为**应标 Mito**，先讨论现行标注 SOP 与版本化标签策略；**本方案不修改任何 mask**，也不能把重标后的分数与原 baseline 直接比较。须另立数据版本和评价协议。
- 若判断分歧或“无法判定”很多，承认单通道图像的语义上限；不要因某些 FP 看起来亮就继续加重负样本、换 loss 或网络，并优先研究标注一致性/额外成像证据。
- 若近边界 FP 的歧义明显多于远距 FP，可另行设计边界一致性研究；不能据此在本轮针对特定 OOF 图像调阈值。

**防泄漏约束。** 抽样使用已完成的 outer-test GT/OOF 只为事后诊断；复核者在判断时对其盲法。复核结果不得改变 frozen split、baseline tag、先前 validation-only decision、已报告 OOF 指标、人工 mask 或当前 fold 的 checkpoint/阈值。任何由本轮 OOF 诊断启发的后续模型对同一 36 张图的五折成绩都必须标为**探索性**；不能把这些已查看过的 outer folds 当成全新的独立测试集。真正的泛化结论需要后来独立取得的标注数据。复核执行前不得把本方案误写成已完成的人工标注审计。
