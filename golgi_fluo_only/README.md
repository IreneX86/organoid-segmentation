# 只用 Fluo 预测 Golgi（2026-11-02 至 11-05）

目标：以后只输入 Fluo（脂质染料）z-stack，就得到 Golgi mask。

**标签说明（重要）**：训练和评估用的 Golgi 标签是**伪标签**，由“看 Golgi 通道的 U-Net”（教师模型，`model_releases/golgi_pilot_20261026`）生成，**不是人工真值**。另有 14 张人工标注只用于最终检验。

## 结论
- 只看 Fluo，模型能大致找到 Golgi 所在的区域（AUC 0.85–0.96，取决于负样本定义），但形状不准：近 Golgi 区域 Dice 约 0.3–0.4，人工标注整图 Dice 约 0.2。
- **推荐使用 `tool/`（v2 2.5D + v3 C7 集成，阈值 0.45）**，只用于粗定位，不要用来测 Golgi 的面积、形态或数量。
- v4（清理标签 + ±12 层输入 + 只用有把握的负样本）**没有变好**：预测面积约为 v3 的 2 倍，近 Golgi 区域 Dice 0.33 vs 0.38。
- Golgi 通道只在部分细胞里亮（染色不全），模型在其他细胞里画出的区域无法用现有数据核对。

## 各版本（3 折，按细胞球划分；评估都在训练时没见过的细胞球上）

| 版本 | 输入 | 主要改动 | 结果（教师伪标签） | 人工标注整图 Dice |
|---|---|---|---|---:|
| v1 | 单层 Fluo | 基线 | 区域 Dice 0.31，AUC 0.83 | 0.20 |
| v2 | z−1..z+1 | 2.5D，每球 16 层 | 区域 Dice 0.35，AUC 0.85 | 0.21 |
| v3 C7 | z−3..z+3 | 7 层 | 区域 Dice 0.34 | 0.21 |
| 工具 | v2+v3 集成 | 阈值 0.45，只用伪标签挑选 | AUC 0.885（人工） | 0.22 |
| v4 | z−12..z+12（步长 4） | 清理标签、改负样本 | 见下表 | 0.13 |

v4 与 v3 在完全相同的层上、用清理后的标签比较（36 个留出层 + 14 张人工标注）：

| | v3 C7 | v4 |
|---|---:|---:|
| AUC（Golgi vs 确定的非 Golgi） | 0.960 | 0.952 |
| 近染色 Golgi 区域 Dice @0.5 | 0.382 | 0.327 |
| 人工标注整图 Dice @0.5 | 0.207 | 0.131 |
| 预测面积 / 标签面积 @0.5 | 6.0× | 12.7× |

注意：v4 的 AUC 用的负样本（细胞核、细胞外、Golgi 周围一圈）更容易区分，不能和 v1–v3 的 AUC 直接比。

## v4 的标签清理规则（与用户逐例确认）
- 膜状伪影：面积 ≥ 300 px、实心度 < 0.40、最大半厚度 < 7 px（贴着细胞膜的细弧）。
- 弥散伪影：面积 ≥ 200 px，且 Golgi 亮度只比周围 8 px 圈高不到 1.25 倍。
- 3D 孤立噪声：该块在 Golgi 通道里连成的 3D 物体，在任何一层都不超过 140 px。M05 上与人工判断 18/18 一致。
- 共删掉教师伪标签像素的 9.8%、人工标注像素的 4.9%。

## 目录
- `tool/`：预测工具（`golgi_predict.py`、说明、模型 SHA256 清单）。**模型权重不在仓库里**。
- `training/`：v1–v4 训练脚本、v4 标签清理（`v4_prepare_labels.py`）、v3/v4 对比（`v4_compare_with_v3.py`）、GPU 启动脚本。
- `results/`：v3 完整指标、v4 与 v3 的汇总对比（JSON）。
- `figures/`：工具在 3 个留出细胞球上的示例、v4 标签清理抽查、v3 vs v4 对比。

原始图像、伪标签、概率图、模型权重和传输包都只保存在本地，不上传。
