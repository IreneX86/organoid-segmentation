# v9 误差分析与 Dice 计算说明（2026-11-12/13）

所有数字：v9，阈值 0.6，留出平面（教师伪标签 36 层 = 每个球体 z71、z103；人工标注 14 层），由未用该球体训练的那一折模型预测（8 方向 TTA）。标签是伪标签/人工标注，不是真值。

## Dice 怎么算（正式指标）
- 范围：离任意标签像素 ≤ 40 px 的区域，扣除被清理掉的伪影块（伪影不算对也不算错）。
- 公式（所有平面合并）：Dice = 2·Σ|预测∩标签| / (Σ|预测| + Σ|标签|)。
- 只在标签附近算，是因为 Golgi 通道只在部分细胞染上，其他细胞里的预测无法核对。代价：离标签 > 40 px 的多检不扣分；完全漏掉的标签仍扣分。
- 阈值是在这些评估平面上选的（v7 也一样），绝对值略偏乐观，版本间比较公平。

| | 伪标签 | 人工 |
|---|---|---|
| Golgi 附近 40 px（正式） | **0.442** | **0.427** |
| 逐层平均 / 中位数 | 0.429 / 0.422 | 0.430 / 0.426 |
| 单层最低 / 最高 | 0.256 / 0.621 | 0.395 / 0.516 |
| 全图（不限 40 px） | 0.202 | 0.250 |

全图 Dice 低主要因为模型在未染色细胞里也画 Golgi（见 figures/v9_masks_with_golgi_channel.jpg）。

## Dice 丢在哪里（analysis/v9_error_breakdown.py, v9_missed_objects_fluo_contrast.py）
- 精确率 0.39 / 0.36，召回率 0.51 / 0.52；多检像素（23.6 万）多于漏检（14.7 万）。
- 多检的 74% 是覆盖了真实 Golgi 但"胖出一圈"（形状不准）；26% 是附近孤立小块，其 Fluo 对比（1.15–1.21）与正确块相近，可能部分是未染色的真 Golgi。
- 36% 的标签块完全漏检；它们偏小（中位 165 px vs 检出的 296 px），56% 在 Fluo 上几乎无对比（< 1.1）。漏检块里约一半最大概率 > 0.4。
- 后处理上限很低（analysis/v9_postprocessing_tests.py）：整体缩放 1–2 px、双阈值、块内相对阈值、平滑、每层最优阈值（作弊上限 0.449）最多 +0.007。
- v7 与 v9 概率平均（analysis/v9_v7_ensemble_test.py）：0.440 / 0.427，不比 v9 单独好。

## 结论与下一步候选
主要瓶颈是训练时要求模型预测 Fluo 上看不见的 Golgi。候选：只用 Fluo 可见的标签训练（亮度 + 形状规则，不可见块设为忽略）；用与评估一致的损失（只在 40 px 内的 Dice）微调；更长训练 / 全部 150 层。
