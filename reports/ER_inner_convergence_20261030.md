# ER Fluo-only U-Net：内部验证选择训练时长的五折对照

日期：2026-10-30。状态：完成、结果校验通过、Pod 已删除。**未找到可靠改善，不升级生产模型。**

## 研究问题与冻结设计

扩充阳性结构裁剪后效果下降，是否仅由训练不足造成？依据 [冻结协议](../docs/er_inner_convergence_protocol_20261030.md)，比较原数据池与扩充池。每折按完整样本隔离：3 个训练、1 个内部验证、1 个外层评估。原池每折24块，扩充池91–94块；内部/外层各8块固定原始 anchor。五折共40个外层裁剪，每个只评估一次。

两组使用相同逐折初始权重、base16 U-Net、BCE+Dice、Adam 0.0003、batch4、p1–p99.8归一化、无增强、阈值0.5。每250更新检查内部验证；1000更新后才有资格选择 checkpoint，最多4000；提升须严格大于0.002，连续4次无提升停止。十个选择决定全部保存并哈希锁定后，独立程序才读取外层标签。无按差分数重跑、改阈值或改规则。

## 训练与收敛观察

累计训练 1077.1 秒（17.95 分钟），十个模型全部由内部验证 patience 提前停止。

| Fold | 原池：选择步 / 完成步 | 扩充：选择步 / 完成步 |
|---|---:|---:|
| 0 | 1250 / 2250 | 1500 / 2500 |
| 1 | 1250 / 2250 | 1000 / 2000 |
| 2 | 2000 / 3000 | 1000 / 2000 |
| 3 | 2000 / 3000 | 1000 / 2000 |
| 4 | 1250 / 2250 | 1500 / 2500 |

内部曲线存在波动、平台或下降；更长训练机会没有使扩充组稳定胜出。这支持“当前数据与规则下，单纯增加更新次数不足以解决问题”，不能证明所有优化都无效或已达到全局最优。预注册的1000步最低资格也有限制：例如扩充fold2在750步内部Dice约0.398，但不符合资格，最终选择1000步；没有事后改选750步。
