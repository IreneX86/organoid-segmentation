# Membrane v4 主体 + v7 保守补入：四个完整类器官的批量交付

本次将用户选定的方案固定为**人工复核用默认流程**，不是宣称已经获得独立外部测试性能。输入为每个类器官同尺寸、同 Z 顺序的 `Memb.tif` 与 `fluo.tif`。v4、v7 都用原 checkpoint、Cellpose 4.2.1.1、`Memb, fluo` 通道顺序、按全局 Z 坐标确定的 local11 p1/p99 归一化、10 层 2D 分批推理和全栈 3D stitching。融合保留 v4 全部原像素和 ID，仅在固定空间重叠、膜/暗区信号、连续层数及唯一 3D 锚定条件均满足时补入 v7。不能确定的候选不自动补入；不基于单个暗洞强迫一核一细胞。

数值结果只用于本批次 QC。源图、人工标签、两个 checkpoint、历史预测均未修改。所有实例 TIFF 为 `ZYX`、`uint16`，背景 0，非零整数为跨层细胞实例 ID；可在 Fiji/napari 中打开和测量。`review.png` 的青色轮廓是 v4，绿色是 v7，黄色为融合新增部分，仅供视觉复核，不是数值标签。

本机交付位置统一为 `outputs/membrane_v4_v7_fusion_20261026/<cell_id>/`，每个目录含 `memb_instances_v4base_v7add_safe.tif`、`review.png`、`manifest.json`。该目录被 Git 忽略；仓库只保留此索引与复现代码。
