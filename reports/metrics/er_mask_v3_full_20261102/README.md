# ER mask v3 全量结果（由 ER.tif 生成，2026-11-02）

共 6 个样本、530 层，每一层都已处理，没有空层。23299 和 23962 的原始 TIFF 超过 400 MB 的上传上限，这次没有处理。

每个样本文件夹（`cell_*`）里有：
- `ER_mask_v3.tif`：ZYX 三维堆栈，每层 1200×1200，uint8，取值 0 或 255。层号与原始 ER.tif / fluo.tif 一一对应，从 0 开始，即 mask 的第 z 层对应原图的第 z 层。
- `ER_positive_region.tif`：ER 信号可见的细胞区域，格式同上。区域外 ER 状态未知，训练时应忽略，不能当作背景。
- `per_plane.csv`：逐层统计，包括删除的亮颗粒数、小亮点数和像素数。
- `manifest.json`：所用参数、源文件和输出文件的 SHA256。

方法是 v2 加 v3 的规则（见 `er_mask_v3.py`）：
- 去除亮颗粒：圆形，且亮度达到附近细管第 90 百分位数的 2 倍以上。
- 限制宽度：所有结构不超过约 5 px 宽。
- 去除小亮点：孤立的小块或紧凑亮团。

规则固定，不针对单张图调参。Fluo 只用来划定大致的组织范围。

**局限**：
- 这些是算法生成的伪标签，不是人工真值。
- 很暗的阳性细胞可能没被划进阳性区，在 23961 和 23963 中可以看到。这些区域会被忽略，但不会被当作背景。
- 很亮、很致密的核周区域里，少数短的网络碎片可能被当成小亮点删掉。
