# Mito 冻结基线误差与标注语义审计

**日期：**2026-10-08。**范围：**36 对已标注、训练时各作为单独 2D 图像处理的 Mito TIFF/mask；真正未来待预测的数据尚未加入。本文汇总已归档的五折 OOF 分析，并对本地只读副本做格式、配对及近重复检查。没有重训、改 mask、重新选阈值或用 outer-test 标签选择模型。像素级“FP/FN”均**相对于现行人工 mask**，不等同于已判定的生物学错误。

![冻结 OOF 的逐图前景占比与误差汇总；图中不含原始显微图像](figures/mito_oof_error_overview_20261002.png)

## 数据完整性与潜在相关性

- 原始 Mac 目录与本地实验打包副本的 36 张输入和 36 张 mask，文件名集合相同，72 个文件逐一 SHA256 一致。每对均为 1200×1200；输入为 `uint16`，mask 为 `uint8` 且像素值恰为 `{0,255}`，训练内部按背景 0、前景 1 解释。前景比例范围为 0.606%–13.405%。这证实二值编码和文件配对一致，**不证明**每个像素的生物学语义正确。
- 对 36 张输入及 36 张 mask 分别计算整文件 SHA256，均无精确重复。将逐图百分位归一化后的输入做 60×60 网格均值比较，最高两图相关为 0.959（`mask_015`/`mask_018`，同一外层 fold）；去掉 20 px 网格背景后以每 4 px 采样的局部纹理相关仅 0.230。跨外层 fold 的最高局部纹理相关为 0.207（`mask_030`/`mask_032`）。没有发现明显**原坐标对齐**的近重复；该检查不覆盖平移、旋转、不同 Z 切面或同一 organoid 的相关图像。原 `organoid_id` 与 Z 顺序不能可靠恢复，因此跨折来源独立性仍未知。
- 36 张中，现行 mask 的归一化前景中位强度均高于同图背景中位强度，差值范围 0.214–0.699；代表图中的标注与可见亮结构大体同位。这仅排除了明显的整体错配线索，不能据此排除局部漏标、不同标注边界或其他亮细胞器。

## 已测量的错误模式

以下为**逐图均值**，不是把数千万像素当作独立样本。冻结 baseline 的 36 图 OOF mean Dice 为 **0.854309 ± 0.062776**，最低 0.726555；IoU/precision/recall 均值分别为 0.750677/0.839055/0.877258。二值 OOF 预测与归档指标逐图一致；先前以冻结 checkpoint 在 CPU 重算的 51,840,000 个像素仅有 2 个二值差异，FP/FN 统计仍以归档预测为准。[原审计方法及区间](mito_error_analysis_20261002.md)可复查。

| 逐图均值 | 前景 ≤5%（7 图） | 前景 >5%（29 图） |
| --- | ---: | ---: |
| Dice / precision / recall | 0.7914 / 0.7272 / 0.8772 | 0.8695 / 0.8661 / 0.8773 |
| FP / TP 像素 | 14,968 / 39,268 | 14,801 / 102,284 |
| 背景 FP 率 | 1.082% | 1.114% |
| FP 距 mask ≤2 px / >10 px | 51.6% / 27.3% | 63.7% / 16.0% |
| FP 强度高于同图 TN 的 p90 | 95.2% | 78.2% |
| FP 局部对比度高于同图 TN 的 p90 | 84.1% | 78.1% |
| FN 距 mask 内边缘 ≤2 px | 88.2% | 92.4% |

低前景图的 recall 与其他图几乎相同，每图 FP 数也相近，然而 TP 少得多；**基数效应足以解释相当一部分 precision/Dice 降低**。低前景 FP 中另有更高比例位于离 GT >10 原像素处，因此不能把所有误差都归结为边界稍宽。FN 多集中在现行 mask 的内边缘，边界定义和弱信号可能重要；距离统计本身不能区分模型漏检与标注边界歧义。低/高前景组的 GT 连通域中位面积组均值都约 159 px，未见低前景图中的组件普遍更小；连通域拆分/合并统计对 1–2 px 边界敏感，不能当作线粒体实例或生物学分支计数。

已有六面板图按稀疏/密集及较低/较高 Dice 分层选择八张，存在近边界红色 FP，也有与标注分离的亮区域红色 FP；高 Dice 图也并非没有 FP/FN。**这些含原始生物图像的面板仅在 Git 忽略的本地 `outputs/mito_error_analysis_20261002/figures/`，不进入仓库。**仅凭单通道外观，无法判断红色亮丝/亮斑是非 Mito、成像伪影、现行 mask 的漏标，还是标注 SOP 对微弱结构的排除。前述“误报”只能用于对既有 mask 的计算评价，不应被写成已证实的人工标注错误。

## 与已有单因素实验的关系

在同一冻结划分下，前景中心 patch 概率 0.60→0.35 与 BCE+Tversky 均未通过各自预先规定的 validation 选择；不宜继续密集扫描它们的比例或权重。三次下采样 U-Net 仅 **1/5** 折入选，门控后 OOF Dice 0.854928，较 baseline 仅 +0.000619，且最差图仍为 0.726555，未形成跨折稳定改进。增加推理 overlap 的验证变化接近零。亮背景 hard-negative 采样的 validation gate **0/5** 入选；锁定策略回退 baseline，OOF 指标不变。其事后 validation-only 诊断中，低前景图每图 FP 平均减少约 370，却伴随 recall −0.00546、Dice −0.00268；不能将“更少 FP”单独视为胜利。未入选候选模型的 outer-test 指标**没有测量**，不能从门控后零差值推断其 raw 泛化分数。详细结果见[第二轮汇总](mito_optimization_round2_20261002.md)与[hard-negative 报告](mito_hard_negative_5fold_20261002.md)。

## 证据边界与下一步

目前最稳妥的瓶颈表述是：**现行标签定义下，低前景图对固定数量的 FP 更敏感；其中部分 FP 位于远离标注的亮结构，部分 FP/FN 涉及边界。**没有证据证明逐图 1–99.8% 归一化是低前景组特有问题；其归一化背景 4×4 网格中位数跨度组均值为 0.209，对照组为 0.232。也没有证据证明必须增加网络复杂度，或证明 loss 调整必然改善 FP。

优先完成[预先固定的盲法标注语义复核方案](../experiments/mito_annotation_semantics_review_protocol.md)：从四个图像层级抽取远距亮 FP、近边界 FP、亮真阴性和已标阳性对照；由熟悉染色与标注 SOP 的至少两位人员先只看输入图独立判断，再看人工 mask 轮廓。**该方案目前只设计、尚未由专家执行。**原图裁剪、坐标、匿名映射和逐人判断必须留在 Git 忽略的本地复核包；Git 只保存不含图像/坐标的汇总。既不改原 mask，也不根据单张 OOF 差图调参。

若之后开展新训练，任何由这些已查看过的 baseline OOF 错误启发的方案都属于**探索性**；同一批 36 张图的外层 fold 不再是完全未受研究者观察影响的独立测试。每折仍须只用本折 training/validation 选择 checkpoint、阈值及候选，outer-test 仅在决策锁定后评估。进一步的泛化主张需要后来独立取得、保留来源信息的已标注图像。
