# Nuc：连续切片人工复核原型（2026-10-16）

在无法找回 167 张人工标注图的来源/Z 对应关系、也没有新的完整目标真值时，本轮**不训练 2.5D 模型，也不修改自动分割标签**。本轮只给已运行冻结 2D 模型的 `cell_22375_NZ_100/fluo_001…010` 制作跨切片人工复核包。原图的 SHA256 按 `input_manifest.json` 核对；冻结预测的 SHA256 另与归档 `verification.json` 核对；复核包保存在本地忽略目录 `runpod_results/nuc_cross_slice_review_20261016_v2/`，入口为其中的 `index.md`。没有启动 GPU。

[复核脚本](../code/nuc_cross_slice_review.py)读取每张中心图及其前后真实切片，使用中心图的 p1–p99.8 作为三图统一的**显示**范围，输出原分辨率 3600×1200 灰度及叠加三联图。洋红色是归档的冻结 2D mask。脚本另外在图像上用固定尺度的宽背景减局部暗芯响应产生每层最多 40 个浏览位置，并用相邻层同 XY 处的图像响应排序；这些尺度未根据用户圈示或目标标签选择。黄色标记不表示模型概率、确认的核、漏核或新标签。`掩膜外`版本只隐藏中心坐标已落在冻结 mask 内的标记，保留原来的排序和编号。

| 只读核验 | 结果 |
| --- | ---: |
| 中心切片及三种原网格三联图 | 10 张；每种各 10 幅 |
| 图像启发式浏览位置 | 400 个，固定每层最多 40 个 |
| 中心点不在冻结 mask 内 | 213 个；不能解释为 213 个漏核 |
| 输入 manifest 中 10 张 TIFF 的 SHA256 | 全部通过 |
| 原图／冻结 mask 运行后哈希 | 未改变 |

一个更简单的“前后层 mask 都有、中心层却完全没有”的检查在内部八张中心层没有找到可用候选：以两邻层交集的 8 连通区域≥256 px、中心覆盖<10% 为固定定义，`fluo_002…009` 每层分别有 18、23、25、25、29、32、38、38 个足够大的邻层交集区域，但符合低中心覆盖的都是 **0 个**。这说明**仅根据已有 mask 填补单层空洞无法找回持续被模型漏掉的结构**；零候选绝不表示没有漏核。图像候选与三层并排图因此只用于人工查看，仍可能包含背景纹理、亮环或 Z 中自然出现／消失的结构。第一张只有后一层可比较，不能把单侧支持当作双侧证据。

在候选生成规则完全固定后，才做一次描述性回看：`fluo_001` 的 11 个此前已经查看过、冻结模型覆盖低于 5% 的粗略圈示框中，有 **6 个**包含至少一个掩膜外黄色点，**5 个没有**。点落在宽松框内不等于定位到了真实核；这些位置已参与过前期错误分析，不能把 6/11 当作召回率或用来调整候选参数。人工审查仍应查看**整张原图**，不能只看黄色点。

本次有意使用归档 `runpod_results/nuc_fluo_preview_20261016/output10` 的冻结预测，而非 Desktop 的 `Nuc_label`。后者 `fluo_001.tif` 与冻结预测有 6,456 个像素不同，并含非二值灰度，可能包含后续编辑；本轮没有读取它作为真值、覆盖它或反向修改模型。目标数据无完整人工真值，因此**不能计算目标 Dice、precision、recall 或候选命中率**；浏览结果不能用于宣称新模型更好。三层同 XY 展示也尚未逐图验证亚像素配准、局部形变或物理 Z 间距。

下一步是对复核包做生物学判断，记录少数具体候选是核、非核还是不确定；若不新增完整目标 mask，这仍只用于定位待复核位置，不能充当正式评估或 2.5D 训练标签。保留冻结 2D 模型和现有预测，不因候选数调整阈值或模型。
