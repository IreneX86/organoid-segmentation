# Nuc 局部对比度单因素实验：原因分析与配对结果

**决定（2026-10-16）：保留原始 Nuc 原型作为工作模型。** 本轮候选对预设合成低对比度扰动明显更稳定，但在未扰动内部验证集上只得到很小、分布不稳定的 Dice 增益，且对已圈示的真实目标图像没有明显找回漏检核。不能将同批次内部验证分数视为外部泛化能力。

## 问题与现有模型

现有 Nuc 专用 2D U-Net 使用 167 对人工标注 TIFF，固定划分为 133 张训练、34 张内部验证。原型模型在 33 张有核验证图像上的平均 Dice 为 **0.956452**（固定阈值 0.50）；其验证集选择的部署阈值为 **0.45**。这些图像之间高度相关：34 张验证图像中有 29 张与某训练输入的相关系数至少为 0.99，因此这个数值不能代表新来源图像的可靠精度。参见[原型报告](nuc_internal_prototype_v1.md)。

上一轮仅增加训练时的空间线性照明扰动。其固定阈值 0.50 的内部验证 Dice 比原型高 **0.001433**，但精确率下降、33 张图中只有 17 张 Dice 改善，且没有明显找回目标 `fluo_001.tif` 中多处经用户粗略圈示的核。因此原型仍是工作基线；空间照明候选只保留作研究比较，详见[上一轮报告](nuc_spatial_illumination_20261016.md)。

## 本轮原因线索

用户修正后的红圈截图只说明**大致存在核的位置**；圈线并非准确边界，也没有给出完整真值或可靠负例。重新运行已保存模型后，若干未覆盖的粗略圈示区域概率约为 **0.001–0.013**，远低于 0.45/0.50。原型验证集已知假阴性像素中，**86.5%** 的概率比 0.45 低至少 0.10，只有 **6.8%** 落在阈值下方 0.05 以内。因此单纯略降阈值难以解释或修复大部分漏检，并可能增加误检；这些百分比来自有真值的内部验证，不是目标图像的漏检率。

| 输入图像统计量 | 训练 133 张 | 验证 34 张 | 前 10 张目标图像 |
| --- | ---: | ---: | ---: |
| 逐图 1–99.8 百分位归一化后的图像第 90 百分位强度：各组中位数 | 0.582 | 0.577 | 0.483 |
| 中等强度像素上，绝对 σ=2 高通残差第 90 百分位：各组中位数 | 0.0253 | 0.0253 | 0.0135 |

局部细节的复现定义为：先逐图做相同百分位归一化，在强度 0.15–0.85 的像素上计算 `|I−Gaussianσ2(I)|` 的第 90 百分位，再取各组中位数；高斯滤波采用反射边界。具体逐图结果、绘图代码及[输入分布图](assets/nuc_input_contrast_20261016.png)分别见 `reports/assets/nuc_input_contrast_20261016.csv` 和 `code/nuc_input_contrast_figure.py`。此前协议中的局部细节摘要使用了未明确写出取样范围的快速审计，数值约差 0.0002；本报告以可复现定义为准，未据此调整冻结实验设置。

目标图像的局部亮暗细节比训练/验证图像弱，尽管它已经过相同的逐图百分位归一化。粗略圈示区域的暗核与周围环带的对比似乎也更弱；其边界不准确，故不能当作精确的核/背景对比测量。圈示区域的尺寸与训练标注核的尺寸范围重叠，**仅用目标较小**解释漏检的证据不足。目标图像也未显示比训练图像更强的平滑照明梯度。综合来看，**局部对比度不足是值得检验的原因假设，而非已证明的唯一原因**。采集差异、标注语义差异、目标核本身的形态，以及训练/验证图像近重复仍可能起作用。

### 标注语义与形态的只读审计

在现有人工 mask 上，面积至少 100 像素的已标注连通区域共有 6,317 个；其外接框长轴的第 10 百分位／中位数／第 90 百分位为 **66／101／134 像素**。用户修正截图中 26 个可用粗略红圈外接框相应约为 **62.5／80／100.5 像素**。两者尺度有重叠，红圈略偏小，但截图笔画、缩放和非精确边缘使两组数字不能被当作同一种实例测量。在 `fluo_001` 的粗略椭圆内部，原型对 26 处提示中的 11 处覆盖不足 5%，本轮候选为 12 处；这里只衡量**对提示区域的覆盖**，不是核召回率，且圈内未必全部属于真值。

用户已确认 `nuc_002.tif`–`nuc_005.tif` 的全黑 mask 表示真正无核；`nuc_006.tif` 的“有核”判断曾参考相邻的 `nuc_007.tif`。只读检查发现验证集 `nuc_005` 与 `nuc_006` 原始输入的相关系数约 **0.9989**，局部可见的部分暗结构也很相似。两张图的不同标签体现了人工判读可能用到相邻层信息，**不能由此推断标注错误**。`nuc_005`–`nuc_007` 都属于原有验证集；以上事后审计不能用于本轮的模型选择或阈值调整。

另用**仅训练集**做近邻审计：全黑标注的 `nuc_002`–`nuc_004` 各自最相似的正例训练输入均为 `nuc_008`，整图相关系数 **0.985–0.988**。在 `nuc_008` 五处已标注核的外接框位置，核芯减周围环带的近似对比中位数为 **−0.1109**，而三张负例在对应位置约为 **+0.0158、+0.0057、−0.0148**。这支持局部可见度差异可能影响标注判读与模型识别的假设；整图相似并不能证明那些负例位置确实有核，也不能保证它们逐像素配准。审计 JSON 和接触图保存在本地 Git 忽略目录 `runpod_results/nuc_low_contrast_20261016/semantic_audit/`，人工标签未改写。

## 已冻结的单因素实验

严格遵守[预注册协议](../experiments/nuc_low_contrast_protocol_20261016.md)与[固定划分及数据哈希](../experiments/results/nuc_internal_split_v1.json)。只在**训练图像 patch** 的既有裁剪及增强之后，以 0.50 概率施加局部对比度衰减：使用反射边界的 σ=64 像素高斯平滑 `G64(I)`，独立随机抽取 `α∈[0.50,1.00]`，计算 `clip(G64(I)+α·(I−G64(I)),0,1)`。其余 patch 原样保留。随机流独立于原有采样/几何/强度增强；人工 mask、坐标、验证输入及原始 TIFF 均不变。

从头训练与原型相同的 2D U-Net；损失、512×512 patch、前景采样、其余增强、归一化、优化器、训练上限、早停、checkpoint 与验证集阈值选择保持一致。**只改变这一项训练增强因素。** 先在未扰动的 33 张有核验证图像上，以双方共同的固定阈值 **0.50** 配对比较 Dice、IoU、precision、recall、最差图和逐图变化；单独报告唯一无核验证图像 `nuc_005.tif` 的假阳性像素。

训练结束后另做一次**不参与模型或阈值选择**的合成压力测试：对 34 张已归一化的完整验证图像统一施加 σ=64、α=0.50 的相同变换，在 0.50 阈值下比较原型与候选。该测试只说明对预设扰动的响应；因为候选正是用类似扰动训练的，压力测试优势不能独立证明真实目标域改善。

只有未扰动验证集满足全部预注册预览门槛——平均 Dice 下降不超过 **0.005**，平均 precision 与 recall 各下降不超过 **0.010**，最差图 Dice 下降不超过 **0.020**——才生成前 10 张目标图像的**独立审阅预览**。预览不得覆盖现有 `Nuc_label`，也不得根据粗略红圈选择阈值或追加调参。门槛通过只表示值得人工审阅，**不等于生产模型升级**。

## 完整训练与未扰动内部验证

在一台 Runpod Secure Cloud A40 上完成一次训练，GPU 预检通过，远端正常退出。最多 100 epoch 的训练由原有早停在 **80 epoch** 停止；固定 0.50 的非空验证集最佳 checkpoint 位于 **第 60 epoch**。候选验证集选择阈值为 **0.50**，原型选择阈值为 **0.45**。以下是双方在同一 33 张非空验证图像、共同固定阈值 **0.50** 下的逐图算术均值；SD 是图像间样本标准差。

| 指标 | 冻结原型 | 局部对比度候选 | 候选减原型 |
| --- | ---: | ---: | ---: |
| Dice 均值 | 0.956452 | 0.957296 | +0.000844 |
| Dice SD | 0.017188 | 0.016816 | −0.000372 |
| Dice 中位数 | 0.963489 | 0.961538 | −0.001951 |
| Dice 最小值 | 0.900239 | 0.899058 | −0.001181 |
| Dice 第 10 百分位 | 0.940023 | 0.945935 | +0.005912 |
| IoU 均值 | 0.917027 | 0.918556 | +0.001529 |
| Precision 均值 | 0.962526 | 0.962401 | −0.000125 |
| Recall 均值 | 0.950615 | 0.952473 | +0.001858 |

33 张图中 Dice **17 张改善、16 张下降**；逐图配对 Dice 变化的中位数仅 **+0.000208**。最大增益为 `nuc_007.tif` 的 +0.017365，最大下降为 `nuc_068.tif` 的 −0.004204。候选最差 Dice 在 `nuc_006.tif`；该图的 precision 从 0.917163 降至 0.869726。非空图像合计 FP 像素从 **245,514** 降至 **236,001**，但唯一真无核验证图 `nuc_005.tif` 的 FP 从 **2,744** 升至 **5,821**；仅一张真负例不足以推断总体无核图误报率。若各自使用验证集选择的阈值，原型 0.45 的 Dice 为 **0.956514**，候选 0.50 为 **0.957296**；这不是共同阈值的单因素对照，也仍然是在同一个开发验证集上选出的策略。

预先固定的**预览门槛通过**：均值 Dice 未下降 0.005，均值 precision/recall 均未下降 0.010，最差图 Dice 只下降 0.001181，少于 0.020。门槛只许可审阅预览，不能升级模型。

## 合成低对比度压力测试与目标预览

在相同 33 张非空内部验证图像上施加预设的 σ64、α0.50 全图对比度衰减，两模型都使用阈值 0.50。原型 Dice 均值 **0.888350**，候选 **0.949543**，逐图配对均值 +0.061192；候选在 **32/33** 张图上提高。中位配对增益为 **+0.023281**，明显小于均值，因为原型在一张合成压力图上 Dice 为零，贡献了很大一部分均值差异。在唯一真无核验证图上，原型产生 **0** 个 FP 像素，候选 **1,050** 个。候选正是用相似扰动训练，此压力测试说明它学会抵抗这个**人工设置的**变换，并非对真实目标图像的独立证据。

门槛通过后，只对 `cell_22375_NZ_100/fluo_001.tif`–`fluo_010.tif` 创建新目录下的审阅用 1200×1200 `uint8` 0/255 mask 和三栏图。三栏图在本地 Git 忽略目录 `runpod_results/nuc_low_contrast_20261016/comparison_panels/`（左：原图，中：原型红色，右：候选绿色），不会上传含原始图像的面板到 GitHub。本地十张源图与 Desktop 现有原图的 SHA256 一致。**没有覆盖** Desktop `Nuc_label`。在 `fluo_001`，候选与原型大体覆盖同一批明显结构，但用户粗略圈示的多处核仍没有被找回。候选的预测前景占比从 **3.440%** 降至 **3.245%**；相对原型新增仅 **564** 像素，移除 **3,380** 像素。前十张候选的前景占比均低于原型，二者平均互相 IoU 为 **0.9130**。互相 IoU 是模型间一致性，**不是准确率**；没有完整目标真值时，不能计算真实目标 Dice、precision、recall 或漏检率，也不能断言每个移除的像素是错误或正确。

## 可复现性、费用与结论

方案和实现于查看最终候选结果前，以 Git 提交 `682248b` 预注册。运行包 SHA256 为 `bb3c9e5df620f9111bf883239a13f751b43d139acc8c198ed6c3e273faf99849`。完整归档及 checkpoint 保存在 Git 忽略的 `runpod_results/nuc_low_contrast_20261016/`：归档 SHA256 `483f1000960aa620aa492ab49da36480649ba723484c58df5253c4d596712f46`；`nuc_unet.keras` SHA256 `97439656a82b77574aa820200fd730c0878084c95d4c84f53fde78e3df27a405`。本地校验器确认 archive/checkpoint、334 个冻结原始 TIFF 的哈希、配置、训练历史、34 张验证概率图与 68 张 mask、压力测试与退出码均通过。

单台 A40 Pod `21spiybvyusvqx` 的实时报价 **US$0.59/小时**，存在约 **67.13 分钟**，已在完整下载校验后删除。Pod、Endpoint、Network Volume、Cluster 列表均为空，持续 GPU 计费速率为零。按存续时间计算的 GPU 费用约 **US$0.66**，另有少量磁盘费用；Runpod 的分项账单仍延迟，最后查询只记入 US$0.128661，**不能当作最终金额**。

**保留冻结原型，不替换现有 `Nuc_label`。** 低局部对比度确实是可量化的目标输入差异，训练增强也提高了对同类合成扰动的耐受性；但未扰动内部验证提升很小、真无核图 FP 增多，而且目标图中已指出的明显漏检仍在。这说明“只做这一种局部对比度增强”不足以可靠解决问题，并不能证明低对比度是唯一原因。训练/验证近重复及目标没有完整 mask 是当前证据的主要限制。训练集内部的近邻审计还提示了局部可见度与标签判读的关系；下一轮应首先用现有数据建立按近重复图像分组的更严格验证方案，再评估单张 2D 输入是否足以复现人工标注的核判读规则。不能用本轮目标红圈或验证集近邻审计回头调当前阈值，也不应继续密集扫描相同增强强度。
